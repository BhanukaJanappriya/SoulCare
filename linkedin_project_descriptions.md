*Best for highlighting technical depth, architectural ownership, and results.*

*   **Project Name:** SoulCare: Stress Management & Clinical Mental Health Platform
*   **Role:** Full-Stack Software Engineer / Core Developer
*   **Associated with:** University of Peradeniya

### Description
```text
SoulCare is a full-stack mental health ecosystem bridging the gap between patients, mental healthcare providers (doctors, counselors), and administrators. I led the development of the application's core backend architecture, real-time messaging services, security layer, and administrative systems.

🚀 Key Contributions & Technical Achievements:

• State-of-the-Art Security & RBAC: Designed a stateless, token-based authentication system using JWT (SimpleJWT) and React Context. Custom-extended Django's AbstractUser to enforce secure role-based access control across four distinct user roles, isolating sensitive clinical records.
• Real-Time Communication: Architected a full-duplex messaging system using WebSockets (Django Channels backed by Redis) for instant patient-provider communication, alongside a modular transactional email notification engine.
• Clinical Appointment Scheduling: Engineered a scheduling engine with a custom server-side conflict resolution algorithm and status state machine (Pending, Scheduled, Completed, Cancelled) to prevent double-bookings and ensure data integrity.
• Administrative Command Center: Built the admin governance module, including secure PDF credential-verification workflows, testimonial moderation pipelines, and a Django-based CSV streaming export utility for analytical game matrix reports.
• Patient & Provider Dashboards: Designed custom React dashboards with live practice statistics (using Django aggregation functions) and rating feedback loops to enhance service quality.

Technologies Used: Django (Python), Django REST Framework, Django Channels, WebSockets, Redis, React, TypeScript, MySQL, SimpleJWT, Axios, Tailwind CSS.
```
